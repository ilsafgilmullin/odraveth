## Известный визуальный долг (для ручного обзора)

- Арт карт, портреты героев, образ Хранителя, фон поля и врат — **временные процедурные ассеты** (D-054); финальные иллюстрации, шрифт и знаки ждут утверждения.
- Портреты героев — силуэты без лица по канону пола; на экране результата и замены карт они крупные и выглядят упрощённо.
- Арт существ на поле одной фракции похож (композиция по фракции/типу/ID).
- «Правила игры» из PRODUCT_BASELINE §8.2 в Prebattle не реализованы.
- Прогноз урона: переключатель сохраняется, но авторитетного API нет — ничего не рисуется.
- Звук не добавлялся (отложен по ТЗ).
