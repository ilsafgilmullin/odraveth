# Stage 5 — герои, коллекция, колоды и подготовка боя

Продуктовые решения: [PRODUCT_BASELINE.md](PRODUCT_BASELINE.md). Здесь описана реализация; её не следует считать набором утверждённых preset колод.

## Источники данных

`HeroCatalog` предоставляет ровно четырёх утверждённых героев и силы. `CardDatabase` загружает 40 утверждённых карт; все доступны с первого запуска без экономики владения, покупок или разблокировок. `CardDefinition.deck_limit` и `DeckValidator.validate` задают лимиты, ровно 30 карт и разрешённые фракции. UI показывает результаты валидации и до добавления копии отключает кнопку при достижении лимита; готовность/запуск всегда дополнительно проверяет `DeckValidator`.

## Сохранение

SaveManager v2 мигрирует профиль v1 с сохранением старых полей. Новые поля JSON: `selected_hero_id` (строковый ID героя), `selected_deck_id` (локальный ID записи), `user_decks` (массив UserDeck) и `prebattle` (`opponent_hero_id`, `ai_difficulty`, `hints_enabled`, `animations_enabled`, `damage_forecast_enabled`). Три переключателя по умолчанию `true`. Профиль содержит только plain data; `MatchState` и незавершённый бой не сохраняются. `AppState.persist_profile` сначала атомарно пишет файл, затем заменяет профиль в памяти, чтобы ошибка записи не уничтожила черновик на экране.

UserDeck: `{id: String, name: String, hero_id: String, card_ids: Array[String]}`. ID генерируется локально и остаётся постоянным при редактировании; имя «Новая колода» является нейтральной начальной строкой. Имя после trim не пусто и не длиннее 40 символов. Некорректные типы, неизвестный герой и структурно повреждённые записи отбрасываются при загрузке; неизвестный ID карты сохраняется внутри неиграбельного черновика, не исполняется. Смена героя не переписывает записи другого героя и снимает несовместимый выбор. Количество колод не ограничено; кнопка «Новая колода» создаёт новый ID, «Сохранить» обновляет открытую запись без дубликата.

## Экраны

- **Hero Select:** четыре равноправные панели с именем, фракцией, названием/утверждённым текстом силы; отдельное подтверждение записывает выбор. Выделение видно по текстовому маркеру. Иллюстрации — цветовые заглушки.
- **Collection:** вертикальная прокрутка всех 40 карт, локальные фильтры фракции/типа/редкости/стоимости, поиск по RU/EN названию без учёта регистра. UI название Neutral — «Нейтральные». Тап открывает общее read-only Card Detail.
- **Deck Builder:** карты фракции выбранного героя и Нейтральные; кнопки добавить/убрать копию, отдельная кнопка информации, имя, счётчик, готовность, сохранение черновика и готовой колоды, список сохранённых колод этого героя, очистка с подтверждением. Первый готовый deck может стать выбранным автоматически; кнопку «Выбрать» можно нажать после проверки `DeckValidator`. Сохранённая колода привязана к герою; смена героя не меняет её состав.
- **Main Menu:** «Играть» открывает Prebattle только при готовой выбранной колоде текущего героя; иначе Deck Builder. «Колоды» и «Герои» открывают соответствующие экраны.
- **Prebattle:** показывает выбранного героя/колоду и готовность, четырёх возможных противников, три сложности и три сохраняемых UI-переключателя. При отсутствующей/невалидной/несовместимой колоде Start disabled; кнопка возвращает к сборке. Mirror match разрешён. Для игрока создаётся точный snapshot ID сохранённой готовой колоды. Временная техническая генерация Stage 4 применяется **только к внутренней колоде ИИ**, без имени продукта; алгоритм и AI decision logic не менялись.

`BattleLaunchConfig.create` копирует массивы колод. Result → Rematch создаёт свежий seed/MatchEngine с прежним snapshot и UI предпочтениями; поздняя правка пользовательской записи не изменяет завершённый бой. «Выбор противника» → Prebattle, «Сменить колоду» → Deck Builder.

## Переключатели UI

Подсказки/Анимации/Прогноз урона сохраняются как presentation preferences. Выключенная анимация сокращает задержки презентации событий, сохраняя порядок. Инструкции для выбранной цели остаются видимыми. Authoritative safe damage forecast пока отсутствует: значение хранится и может использоваться следующим UI этапом, но ложный расчёт в Battle UI не рисуется. MatchEngine, legal commands, AI и RNG от этих настроек не зависят.
