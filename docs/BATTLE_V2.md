# Battle V2 и Mulligan V1 (Stage 7 Visual Alpha)

## Состав

| Узел | Назначение |
|---|---|
| `CitadelBattlefield` (`BattlefieldTheme`) | Фон «Цитадель Нулмериса»: небо, скалы, башни с кольцами, арки с водопадами и каналы по краям, светлое каменное поле с гравированными кольцами в центре. Декор не заходит в игровую область (`set_layout_hints`). Единственное фоновое движение — мерцание водопадов 12 fps, выключается вместе с «Анимациями». |
| `HeroClusterView` | Портрет (он же цель атаки/способности), здоровье, энергия, колода, у соперника — число карт в руке и рубашки, «Осколки души» у Вхоразеля или при ненулевом значении, чип артефакта с зарядами (касание — описание). |
| `BoardPieceView` | Существо на поле: арт, атака, здоровье (урон отмечен цветом и чертой), броня, статусы (Провокация, Натиск, Отложение, Неистовство). Без текста правил. До 7 на сторону. |
| `BattleCardView` | Компактная карта руки из `CardPresentation`: текущая стоимость (повышение ▲), арт, название, характеристики. |
| `HeroPowerButton` | Медальон способности героя со стоимостью и состоянием «ИСПОЛЬЗОВАНА». |
| `MulliganCardSlot` | Карта стартовой руки: касание всей карты отмечает замену (лента «ЗАМЕНИТЬ», штриховка, стрелка — не только цвет), «Описание» под картой. |
| `BattleHistory` | Строки ИСТОРИИ из `MatchEvent`; добор, сгорание и выбор соперника не раскрываются. |

## Компоновка

Поле занимает центр (≈56 % высоты), соперник сверху, игрок снизу, центр свободен. Слева сверху — герой соперника и его артефакт, ниже — превью только что разыгранной соперником карты; слева снизу — герой игрока, артефакт, способность героя и «Осколок импульса» (только когда доступен). Справа — номер хода, «Ваш ход», «ЗАВЕРШИТЬ ХОД» (во время хода ИИ — заблокированное «ХОД СОПЕРНИКА»), действия выбранной карты, необязательные подсказки; сверху справа — «ИСТОРИЯ» и «МЕНЮ». Рука — веер внизу без прокрутки: 3–5 карт крупнее, до 10 перекрываются так, что стоимость и арт видны.

## Взаимодействие

- Касание карты выбирает её; повторное касание или «Разыграть» — розыгрыш без цели. Для карт с целью подсвечиваются только цели из `get_valid_play_targets`, остальное приглушено. Касание пустого поля или Back отменяет выбор.
- Касание своего существа с допустимой атакой выбирает атакующего; цели — из `get_valid_attack_targets`. Тонкая дуга следует за указателем: золотая над допустимой целью, серая с крестом над недопустимой.
- Обязательная инструкция («Выберите цель атаки») видна всегда; «Подсказки» управляют только пояснениями в правой колонке.
- Back: Card Detail → подтверждение выхода → история → выбор Осколков души → текущий выбор → подтверждение выхода.

## Анимации

Добор (карта прилетает к вееру), розыгрыш/призыв, выпад атакующего, всплывающий урон (и «броня −N»), гибель (тающий силуэт), импульс способности и артефакта, баннер смены хода и итога. Всё — твины над уже принятым состоянием; при выключенных анимациях очередь событий проходит с минимальной задержкой, эффекты не создаются, состояние и история те же.

## Mulligan V1

Заголовок «СТАРТОВАЯ РУКА», строка очерёдности (первый — 3 карты; второй — 4 карты и «Осколок импульса», который в замене не участвует), точный герой соперника (портрет, имя, фракция), счётчик «Отмечено для замены: N из M», «ПОДТВЕРДИТЬ РУКУ». Поле за оверлеем затемнено и размыто шейдером `battlefield_dim.gdshader`. Правило «заменённые карты не возвращаются в эту же замену» исполняет движок.

## Прогноз урона

Переключатель сохраняется, но авторитетного API прогноза нет, поэтому UI ничего не рисует и не вычисляет урон сам.
