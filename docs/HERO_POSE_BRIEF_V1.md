# Hero Art V1 — позы четырёх героев (бриф и состояние)

Статус: блоки A–C выполнены в `claude/visual-hero-production-v1` (от PR #12 `02e10ed`);
**финальный арт новых поз не создан** и требуется от пользователя. Блоки D–E (перенос
на остальные экраны, idle-эффекты вне Hero Select) ждут утверждения.

## 1. Почему нужен новый арт

Утверждённые PNG `assets/heroes/*.png` (APPROVED/FROZEN, `masters/README_FIRST.md`)
показывают четырёх героев в одной фронтальной стойке. `tools/art/hero_silhouette_report.py`
измеряет совпадение силуэтов по альфа-каналу (IoU, 1.0 — одинаковые):

| Пара | IoU |
|---|---|
| Вхоразель — Сирравет | 0.87 |
| Кежарин — Вхоразель | 0.83 |
| Кежарин — Сирравет | 0.81 |
| Вхоразель — Тажирион | 0.75 |
| Кежарин — Тажирион | 0.74 |
| Сирравет — Тажирион | 0.70 |

Цель Hero Art V1: **каждая пара ≤ 0.65**. Ориентиры поз ниже дают максимум 0.44.
Обзор: `docs/visual_review/hero_v1/01_current_silhouettes.jpg`, `02_pose_blueprints.png`
(генерирует `tools/art/hero_pose_review.py`; это ориентиры позы, не игровой арт).

В этой среде нет инструментов генерации художественных иллюстраций (нет GPU/моделей),
поэтому новые портреты не нарисованы и программные силуэты не выдаются за арт.

## 2. Позы (утверждаемый бриф) и неизменяемый канон

Канон внешности — `docs/ART_DELIVERABLES.md`; новые позы его не меняют.

| Герой | Поза | Канон, который сохраняется |
|---|---|---|

| **Вхоразель** · Неркатен | вытянутая вертикаль, почти неподвижная стойка, стопы близко; одна рука поднята, управляя энергией душ у навершия резонансного жезла; вторая опущена/скрыта рукавом; асимметрия плеч | мужчина ~50, высокий, сухой; вертикальный грудной резонатор; узкий резонансный жезл; без черепов, косы, большого светящегося камня |

## 3. Технические требования к финальному арту

- мастер: PNG с честной альфой, ≥ 1600×2400, в `masters/heroes/<id>.png` (каталог не
  импортируется и исключён из APK);
- игровой файл: тот же кадр ≤ 1200 px по длинной стороне в `assets/heroes/<id>.png`
  (тот же путь — drop-in через `ArtAssets`, код менять не нужно);
- фигура целиком, вертикальный кадр 3:4/4:5, 3–6 % пустого поля над головой, без текста,
  рамок, чисел и эмблем;
- анатомия, кисти и пальцы проверяются вручную; никаких лишних конечностей;
- приёмка: `python3 tools/art/hero_silhouette_report.py --strict` (код 0), затем
  скриншоты Hero Select / Prebattle / Battle / Result / Story на 1600×900, 1920×1080,
  2400×1080, 2800×1752;
- после замены поправить точки эффектов `HeroIdleFx.ANCHORS` (навершие жезла, рука с
  кольцами, щит) по новому арту.

## 4. Что уже реализовано (блок C)

- **Кадрирование без обрезанных голов** (`HeroPortraitPlaceholder`, общий для всех
  экранов): обрезка от верха кадра с 4 % воздуха над головой вместо центрального
  кадрирования. До изменения при 2400×1080 все четыре героя в Hero Select и Кежарин в
  Prebattle / сюжетной подготовке (1600×900) показывались без головы.
- **Idle-характер героев** (`HeroIdleFx`, слои вокруг арта, сам арт не деформируется,
  ≤ 14 примитивов, без RNG, 30 перерисовок/с только у видимого анимированного портрета):
  Кежарин — пульсирующий жар у земли и искры; Вхоразель — медленные потоки душ к
  навершию жезла и свечение резонатора; Сирравет — вращающиеся кольца искажения у руки
  с эхо и волной; Тажирион — дышащий шестиугольный щит-оберег и золотые частицы.
- **Hero Select**: анимирован только выбранный герой; при выборе — мягкое золотое
  свечение карточки и «разгорание» эффекта; вход экрана — карточки проявляются по очереди;
  заголовок и подзаголовок получили светлую обводку для читаемости. Управление не
  блокируется. С выключенной настройкой «Анимации» — неподвижный кадр без процессов и
  твинов.
- Тесты: `tests/hero_visual_v1_tests.gd` (модуль `hero_visual`).
- До/после: `docs/visual_review/hero_v1/03_hero_select_before_after.jpg`,
  `04_framing_before_after_1600.jpg`.

## 5. Требует утверждения пользователя

1. Бриф поз (раздел 2) и ориентиры `02_pose_blueprints.png`.
2. Источник финального арта: художник или инструмент генерации с правами на
   использование; файлы по разделу 3.
3. Характер idle-эффектов и выделения в Hero Select (блок C) перед переносом на
   Prebattle, Battle, Result и сюжетные экраны (блоки D–E).
